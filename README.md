1 ЛР 
(2 завдання)

з першого пдф-файлу (*МВ.pdf) беремо в роботу 3 ЛР для виконання ДВОХ завдань, що описані у другому пдф-файлі (*Завдання [2025.pdf]).

Для виконання практичних завдань можна використовувати будь-яку мову програмування та будь-яку IDE, а не тільки ті що зазначені у МВ.

Порядок оформлення та подання результатів виконання завдань описано у МВ, пункти 1.5 та 1.6.

На січневих парах будемо розбирати ці завдання, можете до того часу напрацювати та захистити. Захист передбачає демонстрацію результатів онлайн в зум та відповідями на супровідні запитання з тематики курсу та практичного завдання.
